Предложить решение, что если в виде парамтров указаны два файла баз данных, то --compare указыват необязательно.

* Опубликовать precizer в Gentoo через GURU.

* Постепенно перевести внутренние массивы строк с обычных массивов `char *` на массивы дескрипторов `memory`. Такой подход уже используется для `db_file_paths` и `roots`: он делает владение памятью явным, упрощает освобождение ресурсов и позволяет единообразно использовать проверки библиотеки `mem`. Переход следует выполнять поэтапно, сохраняя текущее поведение программы и добавляя тесты для каждого изменённого участка.

* Вывод сообщений о начале хеширования файла. Сейчас выводится уже результат только после выполненного хеширования. Это связано с предыдущей задачей в roadmap, потому что планируется использоваться библиотека slang для переписывания строки в терминале. Почему именно slang? * Быстрое прерывание длительного сравнения баз данных по Ctrl+C. Сейчас во время выполнения `--compare` программа проверяет запрос на завершение между найденными различиями. Однако если сравниваются большие базы данных и различий мало или нет совсем, SQLite может долго выполнять внутренний поиск без возврата промежуточных результатов. В этот момент Ctrl+C уже будет принят программой, но завершение сравнения может произойти с заметной задержкой.

  Возможный вариант решения: подключить стандартный механизм SQLite `sqlite3_progress_handler()`. Он позволяет периодически вызывать небольшую проверочную функцию прямо во время выполнения SQL-запроса. Эта функция сможет увидеть запрос на завершение и попросить SQLite остановить текущий поиск. Такой подход должен сделать Ctrl+C отзывчивым даже при сравнении очень больших одинаковых баз данных.

* Включить сжатие UPX
	* В Docker-сборках AlmaLinux 10 и Rocky Linux 10, когда в поддерживаемых репозиториях появится совместимый пакет.

	* В Docker-сборках Alpine amd64 и Ubuntu arm64, а также в релизной сборке Linux ARM64, когда сжатые исполняемые файлы перестанут аварийно завершаться с дампом памяти. Убрать соответствующие `UPX=true` из `Makefile`.
